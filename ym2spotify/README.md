# ym2spotify

Переносит лайкнутые треки из Яндекс Музыки в Liked Songs в Spotify. Локальный скрипт, без сервера.

## Статус

| Что | Состояние |
|---|---|
| Логика сопоставления, кэш, повторы при лимите, порядок добавления | Покрыто тестами с моками (`python -m unittest`) |
| Работа с реальным аккаунтом Яндекса и Spotify | **Не проверялось**, у меня нет доступа к твоим аккаунтам |
| Размер пачки (40) и лимит поиска (10) | Выставлены с запасом, **не сверены** с актуальной докой Spotify |

Начни с `--dry-run` и `--limit 20`, чтобы увидеть отчёт до любых записей в аккаунт.

## Установка

```bash
cd ym2spotify
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Ключи

| Переменная | Откуда |
|---|---|
| `YANDEX_MUSIC_TOKEN` | Токен аккаунта Яндекса. Как получить: раздел про токен в документации библиотеки [yandex-music](https://yandex-music.readthedocs.io). Токен даёт полный доступ к аккаунту: не коммить, не пересылай |
| `SPOTIPY_CLIENT_ID`, `SPOTIPY_CLIENT_SECRET` | [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) → Create app |
| `SPOTIPY_REDIRECT_URI` | Необязательно. По умолчанию `http://127.0.0.1:8888/callback`. Этот же адрес добавь в настройках приложения Spotify (Redirect URIs) |

По данным поисковой выдачи по [migration guide Spotify за февраль 2026](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide), владельцу dev-приложения нужен активный Premium (он у тебя есть). Саму страницу из своей среды я открыть не смог, так что перепроверь сам.

```bash
export YANDEX_MUSIC_TOKEN=...
export SPOTIPY_CLIENT_ID=...

```

## Запуск

```bash
python ym2spotify.py --dry-run --limit 20   # пробный прогон, ничего не добавляет
python ym2spotify.py --dry-run              # весь каталог, только отчёт
python ym2spotify.py                        # перенос (спросит подтверждение)
```

При первом запуске откроется браузер для входа в Spotify.

| Флаг | Что делает |
|---|---|
| `--dry-run` | Сопоставляет и пишет отчёт, ничего не добавляет |
| `--limit N` | Берёт только N последних лайков |
| `--min-score 0.75` | Порог уверенности для поиска по тексту. Ниже: в отчёт как `low_confidence` |
| `--yes` | Без вопроса перед добавлением |

## Как ищет пару

| Шаг | Запрос | Порог |
|---|---|---|
| 1 | `isrc:<код>` (если Яндекс его отдал) | 0.5 |
| 2 | `track:"название" artist:"исполнитель"` | `--min-score` |
| 3 | Просто «название исполнитель» | `--min-score` |

Оценка = 50% название + 30% исполнитель + 20% длительность (совпадение до 3 секунд). Пример: тот же трек, но длиннее на минуту и другой исполнитель, не пройдёт порог. Ремастер с тем же исполнителем и длиной пройдёт.

## Файлы, которые появляются

| Файл | Зачем |
|---|---|
| `ym2spotify_report.csv` | Статусы `matched` / `low_confidence` / `not_found` для ручной проверки. Открывается в Excel |
| `.ym2spotify_state.json` | Кэш поиска. Если скрипт оборвался или Spotify включил лимит, повторный запуск продолжит с того же места |
| `.cache-ym2spotify` | Токен Spotify |

Все четыре файла в `.gitignore`, это твои личные данные.

## Ограничения

| Что | Почему важно |
|---|---|
| Исполнитель в Яндексе кириллицей, в Spotify латиницей (или наоборот) | Попадёт в `low_confidence`. Правится руками по отчёту |
| Треков может не быть в Spotify (часть российских релизов) | Будут в `not_found`. Это ограничение каталога, а не скрипта |
| Дата лайка в Spotify | Будет датой переноса. Порядок сохраняется: старые лайки добавляются первыми, новые окажутся сверху. Порядок внутри одной пачки из 40 я не проверял |
| Библиотека yandex-music неофициальная | Может сломаться при изменениях на стороне Яндекса |
| Плейлисты, альбомы, подписки на артистов | Не переносятся (ты выбрал только лайки) |
